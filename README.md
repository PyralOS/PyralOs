# PyralOs

PyralOS - An open-source mobile operating system built around privacy, modularity and user control.

We're building a mobile OS from open-source components, with a modern interface and a developer-friendly platform.

# Key points:
- Prioritize compatibility as much as possible
- A true Linux philosophy—unlike what Google claims for Android—meaning indefinite updates until the phone's hardware can no longer handle them
- Support for both Android apps and native/custom apps
- Focus on optimization rather than raw performance
- A highly user-friendly environment
- Easy development for built-in apps
